This HTML preview cannot import photos by itself. Run the Python app on your computer, then open http://127.0.0.1:5000 in that computer’s browser.

From the project folder, run:

python -m venv .venv
# macOS / Linux
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py

# Windows PowerShell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py

Strict reduces false faces. Sensitive finds more faces but can include more objects. SCRFD pretrained weights: non-commercial research only.

JPEG, PNG, or WebP · up to 40 MB per batch · 30 megapixels per image. Photos stay on the machine running the app.

Face detection may miss small, angled, or obscured faces. Untagged photos remain available under “All photos”.
