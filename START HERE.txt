FACE LIBRARY - WINDOWS

1. Extract the entire ZIP. Do not run files inside the ZIP preview.
2. Open the extracted face-library folder.
3. Double-click "Start Face Library.bat".
4. The first start installs dependencies and needs Internet access.
5. A Face Library desktop window opens automatically. No browser is needed.
6. Click Import photos and choose your images.
7. Select a photo on the left, review the faces, enter a tag, and click Save tag.
8. Use the Show dropdown to filter photos by tag.

Close the desktop window to exit. Let active imports finish before closing.

Python 3.12, 64-bit is required. To install it, run in PowerShell:
winget install -e --id Python.Python.3.12 --architecture x64
Then close the launcher and open it again. Other Python versions can stay.
The launcher uses .venv312 and preserves older .venv folders and your data.

The app detects faces and lets you tag them manually. It does not identify
people or automatically match faces. No training photos are needed.

Photos and tags are stored in the data folder on this computer. Keep your
original photos separately. See README.md for details and macOS/Linux commands.
